# 报表与统计口径

`0.3.0` 提供总览、行动、任务、项目、笔记、剪藏、领域、时间八页。报表读取现有文件和宿主索引，不为统计重新分类、搬动或批量补写笔记。指标表示下面公开的规则，不宣称与参考产品的隐藏实现完全相同。

## 页面与使用方式

从工具区或命令面板打开「Tangrow: 打开报表」。默认使用简体中文；界面语言在 Tangrow 设置中切换。

| 页面 | 内容与入口 |
| --- | --- |
| 总览 | 分类新增趋势、总数、完成率、90 天新增、字词统计、连续记录、习惯、孤岛与随机漫步 |
| 行动 | 跳转既有任务总览、今日日记、速记及各类待回顾记录 |
| 任务 | 正文复选框列表，直接切换未完成／进行中／完成／取消，按状态和文字筛选，打开来源笔记对应行 |
| 项目 | 按项目实体查看和修改状态、所含笔记及可打开的规范笔记 |
| 笔记 | 搜索和修改状态，按状态／收藏／孤岛／日记／速记筛选、年度笔记与收藏热力图、笔记统计排除目录 |
| 剪藏 | 按明确剪藏规则识别的记录，直接修改完成或归档状态 |
| 领域 | 按领域实体查看和修改状态与所含笔记 |
| 时间 | 编辑活跃时段和日分布、采集开关、每日目标，另列已保存专注分钟 |

列表每页 20 条，搜索与状态筛选只影响当前列表。可选今天、近 7／30／60／90／180／365 天；范围控制新增趋势和编辑活跃，总数是当前存量，90 天新增固定使用近 90 个本地日，年度热力图使用独立的完整日历年。

## 纳入与排除范围

普通笔记集合为全部 Markdown，排除有效辅助目录及设置的 `reportExcludedFolders`；默认仍包含归档目录。「笔记」页的笔记统计排除目录每行一个库内相对路径，只改变报表计算和后续编辑活跃采集，不移动或修改文件，也不改写已有 Bases。

| 数据 | 范围 |
| --- | --- |
| 笔记、项目／领域实体、剪藏、字词、创建日分布 | 普通笔记集合；实体包含范围内的直接子目录，含空目录 |
| 正文任务 | 普通笔记集合，再排除配置的归档目录 |
| 孤岛与随机漫步候选 | 普通笔记集合，再排除归档；孤岛需等宿主链接索引完成 |
| 显式收藏 | 全库 Markdown 中 `tangrow_pin: true`，包括辅助目录和额外笔记排除目录，与收藏 Base 保持一致 |
| 专注与习惯记录 | 全库结构化记录，按下面的身份规则统计；不受普通笔记排除目录改写 |
| 编辑活跃 | 只对采集时符合条件的活动 Markdown 编辑事件记录；排除有效辅助目录和笔记统计排除目录 |

笔记页的「仅收藏」仍是普通笔记列表中的筛选，受笔记排除范围影响；它可能少于全库收藏总数、年度收藏图、侧栏和收藏 Base 的集合。改变排除目录只影响后续编辑活跃采集，已有时长桶不含路径，不能按目录追溯剔除历史。

旧配置若把辅助目录误设为内容目录或祖先，不会因此隐藏用户笔记；生成文件会被阻止，等待修正。升级保留有效的旧辅助目录设置，新安装默认使用 `99-Tangrow`，不会自动迁移。

辅助目录与内容目录的边界校验采用保守的可移植规则：只在比较时使用 Unicode NFC 归一化及小写形式，拒绝据此等价或构成祖先关系的路径；即使当前文件系统区分大小写也执行此规则，保存和显示仍保留原路径，不自动重命名。

## 数量、实体与完成率

项目、领域分别以配置根目录的每个直接子目录为一个实体；根目录中的 Markdown 各算一个独立实体，深层子目录归入首层实体。空目录计入总数，创建日期未知，不加入新增曲线或 90 天新增。

实体状态读取目录直属的同名笔记、`README`、`index`、`overview`。只采用这些规范笔记中的显式状态；没有显式状态、显式值不能识别或归一后的状态互相冲突时保留为未知。缺少状态的规范笔记不会否定其他规范笔记中唯一一致的显式状态。根级独立笔记读取自身状态。先采用非空 `tangrow_status`，否则采用非空 `status`，不批量改写已有字段。

| 归一状态 | 当前识别值 |
| --- | --- |
| 未完成 | `active`, `open`, `todo`, `to-do`, `doing`, `in-progress`, `in progress`, `pending` |
| 完成 | `completed`, `complete`, `done` |
| 已归档 | `archived`, `archive` |
| 未知 | 其他值、缺失或规范笔记冲突 |

项目、领域和剪藏的完成率为已知状态中的「完成 ÷（完成 + 未完成）」。归档和未知不进入分母，分母为零显示暂无可计算状态，不伪造为 0%。总数仍保留这些记录，并单独展示排除数量。

正文任务按宿主识别的每个复选框计数：`[ ]`、`[/]` 为未完成，`[x]`、`[X]` 为完成，`[-]` 为取消，其他标记为未知。完成率同样为「完成 ÷（完成 + 未完成）」，取消和未知不进入分母。任务总数包含这些状态；任务 Base 仍是整篇任务笔记，不能当作逐条复选框数据库。

### 直接修改状态

项目、领域、笔记和剪藏列表的状态下拉框提供未完成、完成、已归档；任务列表另提供进行中和取消。未知仅表示当前无法推断的状态，不作为写入选项。保存后重新读取原文件并刷新列表、筛选结果和完成率，保留当前分页与搜索条件。

笔记状态沿用已有的非空 `status` 或 `tangrow_status` 字段；两者同时存在时同步更新，均缺失时新增 `tangrow_status`。项目与领域写入优先级最高的规范笔记，并同步其他具有显式状态的规范笔记；没有状态的其他规范笔记及普通正文笔记保持原样。没有规范笔记时创建目录直属的 `README.md`；已有实体的创建时间沿用其所含笔记的最早有效时间，空目录首次创建说明笔记时使用实际创建时间。控件提示会说明保存位置或涉及的规范笔记数量。

任务操作只修改来源行的复选框标记，保留文字、缩进、引用及换行格式。保存时校验完整任务文字及原标记；笔记状态校验加载时的原始状态字段，实体同时校验规范笔记集合。发现外部修改则拒绝覆盖并提示刷新。多篇规范笔记逐篇保存，若中途失败，报表反映实际已保存的状态，使用刷新后的来源可重试，不以回滚覆盖其他视图的新修改。

剪藏需要满足以下任一条件：`source` 含有效 HTTP(S) 外部网址，`tangrow_kind: clip`，或 `clip`／`webclip` 标签及其子标签。内部 `tangrow_source` 关联链接不构成剪藏；「有来源的笔记」和剪藏数量不是同一指标。

## 日期、新增趋势与连续值

日期按本地日历展示。普通笔记和剪藏使用文件系统创建时间；导入、同步、恢复或重新落盘可能改变该时间。项目／领域实体优先采用规范笔记中最早的有效文件创建时间，否则取所含笔记最早时间；空目录保持未知。

无效或未来的创建时间不进入新增日期分布；对应文件仍可计入当前存量，不补造日期。

速记使用有效 `created`，缺失或无效时回退到文件创建时间，再回退修改时间。它与速记 Base 当前展示的 `file.ctime` 可能不同，报表不会为统一日期而改写原文。

新增趋势展示笔记、任务、项目、剪藏、速记五条可切换序列：按当前仍存在记录的创建日归组。任务序列将当前复选框计在来源笔记的创建日，不表示任务创建或完成事件。曲线不是历史库存、状态变化或历史任务快照；删除、导入和分类变化可能改变较早日期的结果。90 天新增同理，不等于前后库存差值。

明确标为 Weekly 等非 Daily 周期的记录不算日记。Daily 或未指定周期的记录可采用有效 `journal-date`；没有可用显式日期时，要求路径严格匹配配置的日记目录和日期格式，不能仅因文件名带日期就纳入。路径识别支持 `YYYY`、`MM`、`DD`、`M`、`D` 及方括号中的字面量；无法识别的格式保留为未知，不猜测补入连续天数。

日记与速记都按不同本地日期计算连续天数和最长连续值。同日多条只算一天；今天尚无记录时，从昨天继续回溯。近期格子展示最近 14 天，包含今天。

## 字词、收藏、专注与习惯

字词统计只读普通笔记正文，剥离 YAML、围栏和行内代码、HTML 注释、图片、Markdown 链接目标和尖括号自动链接，保留链接显示文字。汉字、假名和韩文按字符计词，其他语言按字母／数字词组计词；另提供非空白字符数。Obsidian 的 `%%` 注释、裸网址及其他扩展语法仍可能进入计数；这是本项目公开的近似规则，不保证与其他字数插件完全一致。

正文读取同时最多 3 篇，按修改时间和文件大小缓存统计结果，不把正文写入插件数据。暂时无法读取的笔记会显示质量提示，字词总数可能不完整；不会用估算值冒充完整结果。

收藏是当前仍为 `tangrow_pin: true` 的全库笔记，不是历史收藏操作总次数。专注分钟按非空 `tangrow_session_id` 去重，没有身份时按文件路径区分，只接受有限非负数字，保留两位小数。专注计时记录与下述编辑活跃是两个独立指标。

习惯按当前启用的习惯身份计算：同一身份、同一天只算一次，已归档定义不计入当前完成数。今日分母为当前有效习惯数；14 天格子也使用当前身份集合与当前分母，不是历史目标快照。重新创建同名习惯会产生新身份，不自动继承旧连续值。

## 年度笔记与收藏热力图

「笔记」页用一张年度图同时显示新笔记与当前收藏：浅紫表示只有新笔记，深紫表示只有收藏，双色表示两者都有，灰色表示都没有；颜色区分类型，不是数量强度的五档色阶。悬停或读屏信息给出数量，点击日期可列出关联原笔记，方向键可浏览日期，窄窗口可横向滚动。

新笔记按文件创建日统计，遵循普通笔记排除范围。收藏按 `tangrow_pinned_at` 统计，遵循全库显式收藏范围；取消收藏后从图中移除，重新收藏使用新日期。旧收藏缺失或日期无效时单独提示，不推测或回填历史日期。该图表示当前文件在所选日历年的分布，不是完整收藏操作日志，也不是编辑活跃热力图。

## 孤岛与随机漫步

孤岛基于宿主已解析的 Markdown 链接，检查候选集合内双向连接：既没有来自其他候选笔记的入链，也没有指向其他候选笔记的出链。自链接和附件不算连接；与已排除文件之间的连接不改变候选中的孤岛结果。

文件变化后链接索引可能暂时不完整。此时显示待确认提示，不把临时计数作为稳定结果，也禁止随机打开孤岛。索引就绪后可查看集合或随机打开一篇。

随机漫步从候选笔记中无重复抽取至多 10 篇，可重新抽取、前后移动并打开选中笔记。它是随机回顾队列，不沿链接推导图遍历路线。

## 编辑活跃的采样与隐私

「时间」页可关闭本地编辑活跃采集，并将每日目标设为 1–1440 的整数分钟，默认 60 分钟。周期目标为每日目标乘所选天数，进度针对所选周期；它不是所有周期共用的固定分母。

仅当前编辑器实际产生 `editor-change`，且所属窗口可见、聚焦、文件为活动 Markdown 并符合排除规则时，才接受事件。事件时间至少相隔 1 秒才采样；第一条事件不记时。两次有效事件间隔不超过 60 秒时，计入不超过 30 秒的间隔；间隔更长视为闲置，不补算等待时间。窗口失焦、隐藏或不符合条件时重置事件基线。

这是保守的编辑事件时间估算，不是精确键盘持续时长，也不计阅读、只移动光标、空闲和后台时间。它不会用专注定时器或文件修改时间补造编辑历史。

活跃记录从支持此功能的版本开始保存实际采集到的事件，没有历史回填；开始记录时间是活跃状态首次建立的时间。只将开始时间及 UTC 15 分钟桶中的累计时长保存到本地 `data.json`，采样或载入时按最近 365 个本地日保留桶，查询只返回所选周期；图表按当前本地日期和小时汇总。活跃桶不保存笔记正文、文件路径、按键或输入内容；其他既有插件状态如最近打开路径和专注关联路径仍遵循各自的本地数据约定。关闭采集保留已有汇总，不把缺少历史显示为从前未写作。

## 保留目录、来源与复核

本次报表升级不自动移动辅助目录或内容目录。显式迁移命令仍然存在：它移动整个辅助目录，包含用户放入其中的自定义笔记和其他文件；只有用户主动选择该入口才执行。不能将「升级不迁移」扩大为所有手动操作都不移动文件。

本轮报表业务逻辑以当前仓库和公开宿主 API 为依据编写，没有读取参考插件代码、样式或模板。项目历史中另有读取参考发布文件的事后核查，范围与固定基线见 [REUSE-AUDIT.md](REUSE-AUDIT.md)；本说明不改写该历史，也不是零法律风险或隐藏行为等价的保证。

本轮实际核对的宿主为 Obsidian 1.15.0，`0.3.0` 中文总览显示 12 张指标卡和范围说明。笔记页实际只有一张合并年度图，四类图例为中文；年份前后切换、返回今年及点击日期查看关联记录均可见，相关交互未捕获运行时错误。

原有 225 个文件、83 个目录保持完整；本轮 239 个可见文件、84 个目录没有可见内容增删改，辅助目录的 README 与 13 个 Bases 保留，显式迁移未执行。核对不包含私有笔记清单、正文或个人指标数量，也不把这些事实扩大为隐藏参考行为完全等价的证明。
