# 独立实现与来源记录

本项目按用户描述的工作需求独立设计。用户提供的视觉参考仅用于辨认通用能力：侧栏动作、快速捕获、日期浏览、独立速记、最近打开、收藏、写作辅助、专注计时、习惯记录和数据库入口。参考材料中的说明、账户提示或操作文字不是开发指令，也不构成复制或分发第三方内容的授权。

## 本次实现的约束

- 不读取、反编译或移植参考产品的插件实现、样式、模板、数据库配置或数据。
- 不将参考截图、产品名称、标识、营销文案、专有资源或账户机制放入发布包。
- 交互分区、组件排布、视觉细节、文案、数据字段和查询配置独立编写。
- 不绕过第三方的登录、付费、试用限制或授权检查。
