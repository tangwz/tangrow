报表有 8 页：总览、行动、任务、项目、笔记、剪藏、领域、时间。PARA 四个目录里，项目和领域有实体页，资源（40-Resources）只在后台统计了笔记数（counts.resourceNotes），页面上看不到；归档目录则被整体排除在报表之外。

另外，「近 7/30/…/365 天」这排按钮在 8 个页面都显示，但实际只影响总览的新增趋势、活跃时长目标和时间页。截图里在「笔记」页看到它，下面却是按年显示的足迹图，范围按钮点了没有变化。

三、需要一起决定的问题

1. 侧栏的新建入口选哪种？
A · 标题栏「新建 ▾」改动小，所有页面都能用；多一次点击。
B · 首页内嵌输入框记录最快；首页更长，且只在主页可见。
A + 速记页保留输入框速记页已有完整输入框，两者不冲突。（A 默认就是这样）
2. 「剪藏」并入「资源」，还是两者并列？
并入资源（子页）仍是 8 个标签，PARA 完整。剪藏按规则识别（来源网址 / 标签），可能不在资源目录里，子页上会注明。
新增资源页，保留剪藏页9 个标签，口径各自独立，但标签栏更挤，窄窗口会换行。
3. 资源要不要有状态？
不显示状态资源是参考资料，用笔记数和最近更新衡量。
沿用项目/领域的状态可以统一编辑逻辑，但多数资源的状态会是「未知」。
4. 归档要不要出现在报表里？

目前归档目录被整体排除，这是有意的口径（见 REPORTING.md）。如果想看「归档了多少」，可以在资源页旁边加一个只读的归档计数，不进入列表和完成率。默认建议这一版先不做。

5. 首页「新建」分组删掉后，「打开速记窗口」放哪里？

建议放到速记页的输入框右上角（现在已有展开按钮的位置），并保留命令面板入口。
