02 / REVIEW & ADJUSTMENTS

对照 Astra 方案（ZETTELKASTEN.md + v3）建议调整的 8 个地方

以下 8 项说明原地转化、来源、稿件和报表在工作台里的交互约定。

01 · 对齐 PR #6 代码report-metrics.ts:224

「整理为笔记」不能硬编码平铺到 40-Resources 根目录

PR #6 新增的 collectReportResources() 把 40-Resources 根目录下的每篇独立 Markdown 都算作一个顶层资源条目。如果所有速记整理都强制平铺进 40-Resources/标题.md，整理 30 条速记就会多出 30 个顶层资源条目，冲乱原有的 40-Resources/Cache 等主题子目录。
调整：表单保持轻量，增加一行安静的「存放位置」（可选已有资源主题子目录、00-Inbox 或 40-Resources，记住上次选择）；同时「知识 → 素材」纳入带明确来源的已整理笔记，留在 Inbox 也不丢素材视角。

02 · 补齐核心闭环ZETTELKASTEN.md §5.2 / §11.1

补上普通笔记「原地明确角色」与卡片成熟度切换

v3 让速记先存成普通笔记（“留到需要时明确”），但知识区只提供了「提炼为卡片」——如果这篇普通笔记本身已经写得很清楚，提炼会产生重复的第二份文件。
调整：在知识上下文面板补齐一等动作「明确用途…」（原地标记为卡片 / 文献笔记 / 结构笔记，弹窗预览受控属性 diff，默认不搬动路径，可选移入 50-Zettel），并补上卡片头部的 种子 / 成长中 / 常青 分段切换。

03 · 修正 v3 交互限制v3.html:660 vs §6.2

速记不应限制「最多 1 篇笔记 + 1 条任务」，并补齐中断恢复态

v3 在生成 1 篇笔记或 1 条任务后就把出口按钮置灰禁用，这与 tangrow_capture_results 多次累计列表冲突（一条长速记常含 2 条待办或 2 个独立想法）；同时缺少 capture.processing 未完成凭据的 UI。
调整：出口按钮在标记已处理前可多次使用（文案变为「再整理一篇 / 再加一条任务」），并为中途中断的凭据提供显式的「继续上次处理 / 保留已有结果并结束」状态条（见场景 ① 第二条速记）。

04 · 补齐知识网络动作ZETTELKASTEN.md §6.4 / §8.2

补齐「加入主题」「续写子卡片」、完整 6 种关系与每日回顾

v3 中「所属主题」与「思路的后续」只是只读列表，连接弹窗只有 4 种关系且强制必填理由，也没有每日回顾和待写卡片入口。
调整：补齐「加入主题…」（预览目标结构笔记写入）、「续写后续卡片」（写入子卡 tangrow_parent 并做环路校验）、全部 6 种关系词（支撑/反驳/延伸/举例/对比/相关，允许留空理由作为普通连接），并在知识区增加「回顾与待写」子页与主区完整素材表。

05 · 细化写作与提炼ZETTELKASTEN.md §5.4 / §7.2

写作候选补齐「三种引用 + 排序」，提炼补齐锚点与 1–N 拆分

文档 §5.4 定义了「插入链接 / 引用选段 / 从卡片展开」三种动作及候选顺序，v3 只做了一个点一次就禁用的按钮；提炼弹窗也缺少章节锚点（#事故复盘）、源文回链开关与 P1 多卡片拆分预览。
调整：候选素材支持上下调整论证顺序与三种插入模式，同一材料可多次引用不同段落；提炼弹窗支持保留章节锚点、预览写入文件集合，并可新增第 2 张同批卡片。

06 · 修正报表时间窗口矛盾REPORTING.md:22 vs §8.3

报表「笔记 / 资源」页没有时间范围控件，覆盖率统一用近 90 天或当前存量

PR #6 已明确只有「总览」和「时间」页保留时间范围选择，其他页不设范围控件，解释性副标题也全部改为悬停提示（Tooltip）。而 ZETTELKASTEN.md §8.3 写了“在选定创建时间窗口内的速记结果覆盖率”。
调整：将速记结果覆盖率对齐为固定的「近 90 天」（与现有 gains90 完全一致），在「笔记」页下设 全部笔记 | 卡片 | 稿件 子页，口径说明放入 ⓘ 提示（见场景 ⑦）。

07 · 侧栏高频动作可达性sidebar.ts:208 / capture-panel.ts

保留顶部「当前文件快捷条」与速记「小窗 / 沉浸」入口

把原有主页拆成四区后，如果将「收藏当前页、复制内链、定位文件」全部塞进「更多 → 工具」，日常高频动作从 1 次点击退化到 3 次；速记输入框也漏掉了现有的独立小窗与全屏沉浸按钮。
调整：沿用现有 sidebar.ts 顶部的当前文件条，在右侧放收藏、复制内链和工具快捷图标；速记输入栏底部保留「小窗」与「沉浸」按钮。

08 · 吸收文献捕获意图与来源审计PROVENANCE.md / 文献笔记

文献/剪藏补充可选「捕获意图」，并在 PROVENANCE 记录说明审阅

保存外部文章时记一句“为什么存（捕获意图）”，能有效防止剪藏积灰，并帮助区分“原文梗概”与“我的观点”；作为可选提示加入文献笔记模板，不引入额外必填字段或自动搬移规则。
调整：文献笔记增加可选捕获意图展示；同时按仓库规范在实现或合入文档时补充 PROVENANCE.md 时间线记录（仅阅读外部参考的用户向说明，独立设计架构与代码）。

03 / IN-PLACE VS DERIVATION

什么时候「原地明确角色」，什么时候「提炼为卡片」？

两条路径同时存在，才能既不强迫用户在速记时做分类，又不在知识区制造重复文件。

PATH A · 1 份文件原地明确用途

普通笔记本身已经是一个独立观点或读书笔记

速记整理出的普通笔记 → 打开看了一眼，标题和正文已经足够独立。
点击「明确用途 → 标记为卡片」。

只在该文件补充 tangrow_kind: card、tangrow_id 与 tangrow_stage: seed，保留原有来源链接和正文，可选留在原处或移入 50-Zettel，不产生第二份文件。

PATH B · 原件 + 新卡片提炼为卡片

从长篇 Journal、文献笔记或稿件中抽出一则观点

11 月 17 日事故复盘（600 字经历）或《重试与幂等》读书笔记（2000 字）→ 提炼出 1–N 张原子观点卡片。

原 Journal / 文献保留完整语境；新卡片写入 50-Zettel，通过 tangrow_sources 指向原文件与章节锚点（如 #事故复盘），支持多次提炼与中断恢复。

PATH C · 0 次转换直接用直接选入稿件

还在粗糙阶段，但马上要写进一篇文章里

在「写作 → 稿件」点击「＋ 添加素材」，直接勾选原速记、某天 Journal 或普通笔记。

原速记不需要先转成笔记或卡片，也不会因此自动变成“已处理”。写作过程中如果写出了值得长期复用的新判断，再从稿件反向提炼回卡片盒。
