# 功能对照审计

审计日期：2026-11-08。代码基线为 `0.2.0`，本轮修复版本为 `0.2.1`；宿主为 Obsidian 1.14.5。

结论：已有六个中文工作区、13 个原生 Bases、独立速记小窗和只读概况，但没有完整实现参考界面的全部统计与行为。17 个可见工具均有对应入口，不代表 17 项功能完全等价。现有目录组织继续保留。

## 依据与分类

依据为用户提供的截图、宿主实际界面、当前独立实现与回归检查。截图只展开了工具区及部分报表；其他页签的完整行为无法据此推断。本审计不读取参考插件源码，不包含参考图片、第三方素材或私人笔记名、正文。

| 分类 | 含义 |
| --- | --- |
| 已修 bug | 当前实现自身的错误，本轮补丁需有对应代码与可复核断言，实际界面结果另行记录 |
| 明确未覆盖 | 参考界面可见但当前尚未实现的能力，或当前尚缺少的保护与质量能力 |
| 语义差异 | 存在对应入口，但范围、数据口径、状态或操作结果不同 |
| 截图未展开无法判断 | 缺少足以判断完整行为的参考证据，不作等价结论 |
| 有意独立设计 | 本地存储、独立布局与文案等明确选择，不作为功能缺口的借口 |

## 本轮缺陷修复

以下为本轮确认的实现缺陷及最小修复；源码状态与安装后界面核对分开记录。复核命令与预期断言列在文末。

| 缺陷 | 影响 | 本轮修复目标 | 状态 |
| --- | --- | --- | --- |
| 非文件视图回退到后台笔记 | 报表、速记或图谱没有当前文件，却可能启用并修改后台 Markdown | 以实际 `FileView` 解析当前页；非文件视图禁用文件操作，缓存及动作执行时再次校验 | 代码补丁已落地；实际报表中复制、封面、标题和收藏均为禁用状态 |
| 辅助目录显式收藏范围不一致 | 笔记已标记收藏，Base 可见，侧栏与报表却遗漏 | 显式 `tangrow_pin` 在全库 Markdown 中统一处理，包括辅助目录 | 代码补丁已落地 |
| 目录设置保存失败未回滚 | 内存路径已变更，后续新建可能使用未保存的路径 | 持久化失败后恢复先前内存设置，不改写原笔记或既有 Bases | 代码补丁已落地 |
| 堆叠命令的工作区上下文 | 从侧栏触发可能作用于错误的标签组 | 执行命令前将最近主区叶子设为活动上下文 | 代码补丁已落地；实际主区标签组可进入堆叠并再次恢复 |
| 关闭与自定义时长标签不够准确 | 关闭仅针对 Tangrow；自定义时长实际跨会话沿用 | 关闭标签明确为 Tangrow 侧栏；自定义时长去除“本次”承诺 | 代码补丁已落地 |
| 窄侧栏日期计数字号过小 | 6px 数字影响辨认 | 最小计数字号调整为 8px | 代码补丁已落地 |
| 速记慢保存完成抢焦点 | 用户已转到月历仍可能被拉回输入 | 完成后仅在用户未移走焦点时恢复输入焦点 | 代码补丁已落地 |
| 时间线原文按钮缺少读屏上下文 | 同名按钮难以区分所属记录 | 可访问名称包含对应笔记标题 | 代码补丁已落地 |
| 专注总量的去重与精度不一致 | 侧栏按文件整数求和，报表按会话去重并保留小数，可能产生不同总量 | 两处统一有限非负数字校验、会话身份去重、缺少身份按路径区分及两位小数 | 代码补丁已落地 |

证据入口：[main.ts](../src/main.ts)、[report-data.ts](../src/report-data.ts)、[integration.test.ts](../tests/integration.test.ts)、[report-data.test.ts](../tests/report-data.test.ts)。

实际界面核对中，报表前台时宿主 `getActiveFile()` 仍可能返回最近 Markdown，但 Tangrow 的当前文件为 `null`。真实 Bases 文件视图前台时，复制链接、路径与定位可用，封面和标题等 Markdown 写入动作禁用。没有在真实笔记上触发封面、标题或收藏写入；这些写入边界以源码与文末预期断言说明，不将界面禁用观察扩大为实际写入验证。

## 17 项可见工具

当前入口位于「工具」的不同分组，并非默认同时展开所有按钮。参考列只描述截图可见的操作意图；未经展开验证的写入位置和状态不作推断。

| # | 参考可见工具 | 当前对应行为 | 分类与边界 |
| --- | --- | --- | --- |
| 1 | 当前页行宽 | 「展开当前页行宽」通过插件样式放宽当前路径的 Markdown 视图 | 语义差异：同一文件的多个视图一起变化，不修改宿主行宽设置 |
| 2 | 刷新识别 | 「刷新索引」清除任务文字缓存并重建 Tangrow 快照 | 语义差异：不重新解析宿主元数据、不补属性、不识别笔记分类 |
| 3 | 复制内链 | 使用宿主 `generateMarkdownLink` 生成当前文件链接 | 支持 Markdown、Bases 等文件；链接格式遵循宿主，不推断参考格式 |
| 4 | 复制路径 | 复制库内相对路径 | 语义差异：没有复制操作系统绝对路径；截图无法判断参考采用哪种路径 |
| 5 | 显示文件位置 | 打开文件树并尝试定位当前文件，兼容调用失败时提供路径指引 | 宿主集成；需实际界面验证，支持 Bases |
| 6 | 折叠列表 | 执行编辑器 `foldAll` | 语义差异：折叠所有可折叠章节，不限于列表 |
| 7 | 展开列表 | 执行编辑器 `unfoldAll` | 语义差异：范围同上，不是列表专用操作 |
| 8 | 添加封面 | 选择现有库内图片，写入 `tangrow_cover`，在阅读视图标题前显示 | 语义差异：没有实时预览封面；只接受库内指定图片格式，不处理远程封面 |
| 9 | 标题添加时间 | 给正文第一个一级标题补充 `YYYY-MM-DD`，必要时创建标题 | 语义明确：不重命名文件；另有正文光标时间戳动作，二者分开；参考写入位置未确认 |
| 10 | 打开报表 | 复用独立 Tangrow 概况标签页 | 明确未覆盖部分报表指标，详见下表，不能按“有报表入口”认定等价 |
| 11 | 插件设置 | 打开 Tangrow 设置页，宿主兼容调用失败时提供操作指引 | 有意独立设计：配置本项目，不提供参考产品账户或授权机制 |
| 12 | 收起面板 | 关闭 Tangrow 侧栏叶子 | 语义差异：不折叠整个右侧栏，其他右侧插件保留 |
| 13 | 文件列表 | 打开并激活左侧文件树 | 语义差异：不是显示／隐藏切换，不显示伪造的开关状态 |
| 14 | 堆叠标签页 | 定位最近主区标签组后调用 `workspace:toggle-stacked-tabs`，不可用时给出菜单指引 | 宿主 1.14.5 实际点击后主区进入 `mod-stacked`，再次点击恢复；这是当前宿主结果，不作跨版本保证 |
| 15 | 全局行宽限制 | 「展开全局行宽」给全部 Markdown 增加放宽样式，并清空临时单页例外 | 语义差异：是额外放宽；关闭仅恢复宿主原宽度，不保证重新限制行宽 |
| 16 | 明暗主题 | 调用宿主明暗切换命令，不可用时指引外观设置 | 宿主集成；按钮不伪装为已读取当前状态的开关 |
| 17 | 主题色 | 打开宿主外观设置页 | 语义差异：没有独立主题色选择器，用户在原生设置中调整 |

宽度最终效果受宿主设置和主题影响。单页宽度状态按路径保存于当前运行实例，全局默认保存在插件数据。兼容适配器使用的设置、命令和文件树定位能力不是完整公开 API；升级宿主后需要重新核对。证据入口：[sidebar.ts](../src/sidebar.ts)、[main.ts](../src/main.ts)、[compat.ts](../src/compat.ts)、[styles.css](../styles.css)。

## 13 个 Bases 与原有目录

全部视图都先筛选 Markdown；文件名和属性键保持英文，显示名默认中文。数据库是原位置笔记上的查询，不是笔记副本。

| 文件名 | 当前筛选口径 |
| --- | --- |
| `Tangrow Notes.base` | 除辅助目录外的 Markdown，包含归档 |
| `Tangrow Recent.base` | 上述笔记中最近 7 天修改的文件 |
| `Tangrow Projects.base` | 项目目录中的笔记，排除辅助目录 |
| `Tangrow Areas.base` | 领域目录中的笔记，排除辅助目录 |
| `Tangrow Resources.base` | 资源目录中的笔记，排除辅助目录 |
| `Tangrow Inbox.base` | Inbox 目录中的笔记，排除辅助目录 |
| `Tangrow Sources.base` | 非空 `source` 或 `tangrow_source`，排除辅助目录 |
| `Tangrow Captures.base` | `tangrow_kind` 为 `capture` |
| `Tangrow Pins.base` | 显式 `tangrow_pin: true`，不排除辅助目录 |
| `Tangrow Drafts.base` | `tangrow_kind` 为 `draft` |
| `Tangrow Focus.base` | `tangrow_kind` 为 `focus` |
| `Tangrow Habits.base` | `tangrow_kind` 为 `habit` |
| `Tangrow Task notes.base` | `task` 标签或 `tangrow_kind: task` 的整篇笔记，排除辅助目录 |

已确认的语义与配置限制：

- 任务 Base 是笔记粒度，不能将每个正文复选框当作独立行；既有 Tasks 总览继续使用，插件不另建平行任务存储。
- 速记月历按 `created → file.ctime → file.mtime` 取日期，速记 Base 的时间列显示 `file.ctime`；导入、同步或修改属性后可能不同。
- Bases 定义了列顺序，没有默认行排序；它们不保证与侧栏最近修改或速记创建时间倒序一致。
- 「近期修改」Base 限最近 7 天；报表的最近修改列表取前 8 篇，不限 7 天；最近打开历史最多 50 个路径，按实际打开顺序，三者不是同一集合。
- 修改路径设置不会重写已有 Bases，保留自定义查询；旧视图可能继续查询旧路径，需手动调整或选择新辅助目录后重新初始化。
- `supportFolder` 应为专用补充目录。当前仅验证路径语法，没有防止将它设为项目、领域等现有目录或祖先；这样会令该目录中的笔记从部分统计中排除，虽然不会搬动或删除文件。

证据入口：[bases.ts](../src/bases.ts)、[model.ts](../src/model.ts)、[managed-files.ts](../src/managed-files.ts)。

## 六个工作区与尚未修正的质量边界

| 工作区 | 当前范围 | 边界与分类 |
| --- | --- | --- |
| 工具 | 分组动作、新建笔记、项目子目录、原有日记和任务页、数据库入口 | 17 项对应行为见上；不是原布局或状态的逐项复制 |
| 速记 | 共享持久化输入、42 格月历、单日／全部时间线、12 条逐次加载、约 240 字符纯文本摘要、桌面分离窗口 | 原文打开后编辑，不在侧栏完整渲染 Markdown；移动端使用主区标签页；参考隐藏行为无法判断 |
| 收藏 | 显式收藏与真实最近打开；历史去重、最多 50 个路径，初始 8 项逐次展开 | 与按修改时间的 Bases 分开；本轮统一辅助目录显式收藏范围 |
| 写作 | 持久化标题与正文、当前草稿字数、保存为 Inbox 草稿笔记 | 没有全库字数；多侧栏写作实例未共享更新，旧实例再次输入可能覆盖另一实例的新文本 |
| 专注 | 自定义时长、开始／暂停／继续／结束／取消、持久化恢复与会话记录 | 自定义时长在同一侧栏实例中跨会话沿用，用户可选择恢复默认；本轮去除“本次”标签，不声称每次自动重置；不等于编辑活跃时长 |
| 习惯 | 每日幂等打卡、14 天格子、连续值、归档保留记录 | 没有归档恢复入口；重新添加同名习惯会产生新身份并重新计数；参考完整规则无法判断 |

以下保护与质量能力尚未覆盖，本轮没有把它们作为已修 bug：

| 已确认问题 | 影响与证据 |
| --- | --- |
| 超长速记摘要处理没有先限制输入前缀 | 在截取 240 字符前，多轮正则和字符数组仍扫描全文，长文本可能阻塞界面；见 [capture-panel.ts](../src/capture-panel.ts) |
| 习惯逐日状态的读屏信息不足 | 格子只汇总次数、缺逐日状态；时间线按钮上下文本轮单独修正，不能替代习惯网格的逐日可访问性；见 [sidebar.ts](../src/sidebar.ts) |

共享速记同时提交同一版本会合并一次创建，但若笔记已写入、随后草稿状态保存失败且应用在重试前退出，旧草稿可能在重启后恢复；不承诺进程崩溃后的跨重启去重。此限制与已保存专注记录的幂等恢复分开。

## 有意独立设计与无法判断的范围

采用独立布局、代码、文案和 `tangrow_` 属性；图标来自宿主，本地保存，无账户或订阅，不复制参考产品源码、样式、数据库配置或素材。这些措施用于降低来源与表达复制风险，不能保证全部法律风险为零，也不意味着已补齐上述功能缺口。来源记录见 [PROVENANCE.md](PROVENANCE.md)。

参考图没有展开写作、专注、习惯等页签，也没有公开数据库 schema、任务分母、封面写入格式或编辑活动规则；这些属于无法判断的范围。当前基础工作流只按已确认需求实现，不宣称完整兼容参考产品的隐藏行为。

## 目录与验收边界
